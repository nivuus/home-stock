# These four are NOT test tools, and none of them is a dependency this
# repository chose. pytest-homeassistant-custom-component installs Home
# Assistant WITHOUT any per-integration requirement, so every component this
# integration needs must be listed here by hand or its setup fails:
#
#   home-assistant-frontend  frontend imports hass_frontend at setup. Without
#                            it frontend fails, panel_custom fails with it
#                            (manifest.json declares panel_custom), and
#                            home_stock never sets up: 471 failures and 53
#                            errors, all of them "'MockConfigEntry' object has
#                            no attribute 'runtime_data'".
#   hassil                   conversation imports it at module level.
#   home-assistant-intents   same, beside hassil.
#   PyTurboJPEG              camera's img_util imports turbojpeg.
#
# The last three come in through custom_components/home_stock/receipt/task.py,
# which imports homeassistant.components.ai_task: ai_task -> entity -> task ->
# camera, conversation, image, media_source. Note that ai_task/task.py imports
# camera and image WITHOUT declaring them in its own manifest, so the closure
# is wider than `dependencies` alone suggests.
#
# Nothing had ever noticed any of this: ruff failed before pytest was ever
# reached on this repository, so the Home Assistant suite has NEVER run in CI.
#
# Every version is the one declared by the matching component manifest in the
# Home Assistant release the pin above resolves to (2026.8.2). Bumping
# pytest-homeassistant-custom-component moves that release, and these with it.
home-assistant-frontend==20260729.7
hassil==3.11.0
home-assistant-intents==2026.7.30
PyTurboJPEG==1.8.3

# ruff is pinned HERE, and this is the only place that can pin it. The shared

# `pip install ruff pytest`, which resolves to whatever was published that
# morning; but it installs THIS file first, so a version already satisfied is
# the version the control runs with. Unpinned, the rule set moves under the
# repository between releases - see ruff.toml for the measurement and for the
# selection this code is written against.
